# R6 extraction pilot

Date: 2026-09-07  
Status: passed and closed; codebook frozen

## Ten-paper calibration set

The pilot deliberately spans state resolution, differentiation mechanism, evidence maturity, and review role:

| Record | Calibration purpose |
|---|---|
| R0002 | inherited continuous macro node foundation |
| R0003 | aggregate partial FIFO and multi-commodity state |
| R0007 | integer-individual LTM and exact identity |
| R0008 | movement/turn queue state |
| R0012 | differentiable agent logic and smoothing |
| R0013 | differentiable micro/macro hybridization |
| R0014 | differentiable continuous LTM and route choice |
| R0017 | discrete-packet mesoscopic signal-control model |
| R0024 | secondary systematic map |
| R0029 | contextual differentiable microscopic task |

The pilot will test whether the codebook cleanly distinguishes semantic identity from realized order; continuous mass from packets/vehicles; aggregate supply spillback from explicit physical storage; exact program derivatives from surrogate gradients; and internal optimization from external gradient usefulness.

## Pilot result

All ten papers could be coded without changing the eligibility boundary or adding a new behavioral category. The pilot prevented three likely conflations: commodity identity is not exact realized order; forward comparison with a microscopic simulator is not gradient-transfer validation; and automatic differentiation through a smoothed agent program is not the same derivative contract as AD through an unsmoothed piecewise-continuous traffic model.

One bibliographic correction was made: R0013 is a peer-reviewed ACM Transactions on Graphics/SIGGRAPH Asia 2022 article, DOI `10.1145/3550454.3555492`, with arXiv `2210.08046` as its accessible author version.
