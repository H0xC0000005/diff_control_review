## Scientific question and fixed opening boundaries

For a genuine, source-supported local ramp-meter task, can a qualified compact
aggregate model, including credible memory or additional continuous state,
preserve the richer model family's response to changes in metering? Identify
which detail, if any, a defensible reduction must retain to preserve that response.

This is a relative representation/control-fidelity claim. Complete fine
initialization can be declared publicly for a model comparison, with the same
physical scenario and forcing and each reduction's projection made explicit.
Knowing the fine state in principle does not certify any particular compressed
dynamic model. Conversely, failure of one weak reduction proves nothing about
all aggregate models. Declare initialization/projection, estimator access and
retained memory separately; no richer controller gets private reference truth.
Replaying the richer model or supplying its hidden state at each update is not
an independent reduced-model closure.

Keep one controlled ramp/local merge, common open-loop metering-rate schedules,
continuous conserved traffic mass, finite receiving/storage obligations and
complete all-stream TST through clearance, including entrance waiting. Do not
change actions to individual gap timing, add lanes/ramps to force a distinction,
omit waiting, impose private driver realizations, or restrict a rival to a
memoryless average. No particular lane/cohort/order representation is presumed
necessary. A compact sufficient model is a valid result.

This is methodology/source/static analysis. No implementation, SUMO installation
or run, traffic experiment, numerical derivatives or optimization is opened.
Detailed equations/comparison settings follow surviving admission in Stage 3;
general gradient/readiness obligations follow in Stage 4. Forward discrepancy,
sensitivity discrepancy and useful control directions remain distinct claims.

## Work sequence and admission obligations

1. **Admit control leverage before richer-state necessity.** Extract the actual
   meter-to-release-to-entry-to-service-to-exit chain, queue/storage boundaries
   and population/objective from the source family. Assess the transfer to
   finite demand/clearance and complete TST. Distinguish changing discharge from
   merely moving waiting between ramp and mainline. A source's throughput or
   combined-controller benefit is not a matched task certificate. If this
   prerequisite fails, report it without inventing a favorable control effect.
2. **Specify the reduction being challenged.** Identify the richer family's
   potentially consequential state and the projected aggregate state, parameters,
   input/observation interfaces, updates and memory. Inspect the strongest
   plausible compact/spatial/memory alternatives. Distinguish source models from
   reviewer adaptations. A lane-macro competitor retains lane detail; retaining
   a sufficient continuous statistic may be enough without identity metadata.
3. **Audit intervention response within those named families.** Determine what
   source or static evidence supports different predicted service/exit responses
   to the same rate intervention after fair initialization/projection. Ask whether
   a compact refinement removes the distinction. Report forward, response and
   action-relevance support separately; a transient mismatch or finite-horizon
   throughput gain alone is partial evidence. No numerical accuracy threshold,
   physical model or gradient estimator is selected just to force admission.
4. **Synthesize and stop.** Name the surviving task/family and reduction claim,
   or give a compact-sufficiency, control-negative, representation-negative or
   evidence-limited disposition. State source-to-task gaps and the smallest
   next question. Do not automatically open Stage 3.

Operational initialization/log evidence missing in BP-I is not a prerequisite
for this model-family comparison. A later claim about deployment/estimation
would require it. Stage 2 still needs a defensible declared initialization and
matched knowledge contract; it cannot treat missing evidence as permission for
unequal controller information.
