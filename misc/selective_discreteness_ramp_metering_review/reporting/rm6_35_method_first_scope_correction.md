# RM6.35 — Scope correction and method-first reopening

Date: 2026-10-01. Status: **RM6-UG1 withdrawn without disposition; superseded by RM7.**

## User correction

The user identified that RM6 still inherited the historical review's
implementation-anchored question: it sought a mechanism compatible with the
current simulator and treated expansion beyond existing physics as an early
stop. That is not the intended reopening.

The ramp branch is to be reconsidered in the same method-first manner as the VSL
line. The traffic/control task and information question must be selected before
choosing a model family or asking whether it fits current project code.

## Effect on RM6

RM6's source-transfer audit remains useful evidence that a continuous finite-
receiving family exists. Its RMA-A/B/C gate is withdrawn because all three
candidates were framed after prematurely selecting that family and retaining
project compatibility as a task-admission condition.

No RM6 candidate is accepted or rejected. RM6 is preserved as a superseded
reopening attempt, not treated as a scientific negative result.

## Corrected method-first sequence

1. **Task selection and formulation:** choose a ramp geometry, infrastructure
   action, outcome, strong observer and candidate hidden-information contrast.
2. **Predecessor and mechanism review:** test whether the formulated task has a
   strong baseline, an isolatable resolution gap and a credible richer
   evaluator, without requiring compatibility with current implementation.
3. **Model-family and minimum-information review:** compare aggregate,
   compressed, lane-resolved and finer local state; select equations only after
   the task survives the evidence review.
4. **Information-to-decision and gradient review:** construct or obstruct the
   matched-history action distinction before implementation or empirical work.
5. **Research-ready plan:** only then evaluate project integration, software and
   experiment execution.
