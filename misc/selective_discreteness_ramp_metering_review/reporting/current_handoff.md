- **RM4 and RM5 closed; overall review closed.** The user accepted the negative role verdict and the final objective-voice colleague report. D1 is complete, but its E1 formulation recommendation and all remaining RQ3--RQ5 formulation work are halted. Do not resume them from historical gates.
- **Colleague-facing argument fixed for the draft:** reject the proposal to adopt ramp metering as a parallel new task. A formulation compatible with the current architecture has little distinctive selective-mesoscopic value; a formulation with stronger freeway-mesoscopic value requires behavior outside the current model and substantial additional work. State this in semantic language, without internal phase/question/candidate/milestone codes. Exclude project consequences, reopen conditions and workflow administration from the report.
- **B1-P definition:** one metered input and one mainline input with non-overlapping eligibility intervals merge into one ordered stream; a first-order link carries it to a fixed-supply one-stream/two-output point diverge. This is an intentionally elementary proof task, not ordinary overlapping/multilane freeway traffic.
- **RQ1:** conditionally positive for B1-P; negative under current contracts for general overlapping/multilane B1. **RQ2 after feedback 20:** B1-P has application and causal-chain distinctness but not enough representation-hypothesis orthogonality for the requested primary parallel-task role. It remains credible only as an optional transfer/ablation fixture.
- Direct differentiable freeway/ramp precedents exist: RM0024 is a first-order coordinated-ramp discrete adjoint, RM0026 is a smoothed-CTM gradient/MPC method, RM0025 is a multiclass network discrete adjoint, and RM0030 is freeway METANET automatic-differentiation calibration. This corrects a narrow urban-only characterization but makes generic differentiable ramp metering a weak selective-meso novelty argument.
- Mesoscopic ramp evidence RM0027–RM0029 chiefly adds route/departure response, stochastic/event resolution and network scale. It does not establish exact queue rank as the characteristic ramp-metering advantage over macro models.
- No M1 G2 reopening is needed only while non-overlap is a hard verified condition. Overlapping inputs require explicit G2 reopening. M3 remains responsible for exact versus relaxed service and any within-bin compression.
- RM0016 is a destination-aware second-order model, not a ready-made first-order matched baseline. Its joint comparison changes several factors; its OD ablation is narrower.
