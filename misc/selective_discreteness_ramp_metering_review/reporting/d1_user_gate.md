## Problem statement

Should RM4 now formulate the narrow chronology-safe point-diverge task, defer B1, or broaden the review to resolve ordinary overlapping merge/lane physics?

## Assumed model-chain function

The optimized meter changes upstream admitted route-mass timing. A first-order merge and long link propagate that traffic to an unactuated route-sensitive point diverge. The experiment asks whether exact ordered continuous mass changes downstream service and useful metering sensitivities beyond strong aggregate/composition-memory alternatives.

## Core gap

D1 found a credible downstream point-diverge order mechanism but no source-backed physical total ordering for simultaneous continuous mainline/ramp inflows. The narrow task avoids this gap by requiring non-overlapping eligibility intervals. The user must decide whether that intentionally idealized proof case is worth formulating.

## Candidates

### E1 — formulate chronology-safe B1-P (provisional recommendation)

Proceed inside RM4 to RQ3–RQ5 only for one metered input, one mainline input, a non-overlapping merge chronology, one first-order propagation link, and a fixed-supply one-stream point diverge. Define the action, objective, paired order cases, comparator ladder, derivative checks, evaluator mapping, ownership and stop rules. Preserve its status as a proof-of-mechanism/transfer task.

**Pros:** satisfies RQ1 without lane changing; gives RQ2 a distinct upstream-control/downstream-service chain; directly tests whether ordered information survives propagation; supports an honest negative result; no current M1 reopening is needed under the non-overlap restriction.

**Cons:** deliberately idealized and not representative of ordinary continuously occupied freeways; the non-overlap admissible set may constrain the control problem; time-step refinement may show that cohort aggregates suffice; M3 still must approve the exact service realization before implementation.

**Dependencies/consequences:** formulation must make non-overlap an acceptance condition, include strong aggregate/cohort/refinement baselines, and prohibit operational generalization. Any later overlapping-flow variant reopens M1 G2.

### E2 — defer B1

Record that a narrow proof case exists but judge it too contrived to warrant a parallel downstream task. Close RM4 with a conditional/deferred conclusion.

**Pros:** avoids investing in a task with limited real-freeway representativeness; keeps project attention on the approved signal-control anchor; avoids pressure to generalize an idealized merge.

**Cons:** forgoes the cleanest available test of long-range order/gradient transfer; does not determine whether aggregate time cohorts are sufficient in this setting.

**Dependencies/consequences:** no project change; revisit only after M3 or new evidence changes the cost/value balance.

### E3 — open a separate merge-order/common-physics review

Do not formulate the restricted task. Instead review physical chronology for overlapping continuous streams and/or distributed multilane exit access.

**Pros:** could yield a more representative freeway application and remove the non-overlap restriction.

**Cons:** materially broader; may require lane-changing, headway/vehicle interactions, capacity-drop physics, or a change to the M1 merge contract; risks changing the project's narrow contribution.

**Dependencies/consequences:** explicit new scope and contract-reopening authority; this cannot proceed as a refinement inside the current approved review.

## Provisional recommendation

**E1.** B1-P is sufficiently compatible and scientifically distinct to justify a bounded formulation pass, provided it is labelled a mechanism-isolating proof task and its non-overlap restriction is treated as a hard validity condition. This recommendation does not assume selective order will win and does not authorize implementation.
