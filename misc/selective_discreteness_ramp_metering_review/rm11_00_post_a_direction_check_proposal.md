two-mainline-lane aim, finite storage/receiving, all-stream TST through clearance,

restrictions merely to obtain a distinction. A's recovery evidence remains useful
background; an essential source mechanism is not excluded to force C to be pure.

RM10 contributes four safeguards:

1. Bind actual source setting and what is initially known before adding state.
2. Compare adequate aggregate laws and spatial state with the **same available
   observation support**; finer internal cells do not grant new measurements or
   oracle initialization.
3. Separate different predictions from different useful common actions under
   complete TST. No deep gradient work before this distinction is defensible.
4. Known complete initialization with exact deterministic public dynamics remains
   sufficient in principle. New geometry cannot create unknown state from that
   premise. Aggregate-only initialization is a different knowledge contract and
   must be supported by the task, not chosen for a favorable result.

## Main decision RM11-G2

**Problem statement.** Which next review has the best defensible route toward
the core freeway information/control question after A's scoped negative result?

**Assumed model-chain function.** Ramp control changes release, road/ramp storage,
actual merging and downstream exits. The review must establish what extra traffic
information matters to useful control and then define a credible gradient path.

**Core gap.** No admitted A task closes genuine initialization, full-history
unresolved state and useful actions. C has physical antecedents but no completed
certificate either. More physical detail alone cannot repair this gap. Alternatives
must be compared by actual changes to information, action, physics and claims.

### C-revised — finite merging opportunity, with C0 first (recommended)

Review a source-grounded single-ramp setting with an actual finite merging lane.
Ask whether remaining opportunity to merge and shared receiving constraints
leave relevant lane/access information unresolved by aggregate observations and
history. Begin with what a well-resolved aggregate CTM or source-derived lane
macro model can represent and infer. Do not compare only to an inadequate point
merge or assume public distance-to-lane-end is hidden.

**Task/model-chain result sought:** a concrete setting, observation/init contract,
fair aggregate rival and defensible action-relevant residual, or a scoped negative
admission result. Rate-only control/TST remain the default. Additional state is
selected only after the gap survives; no subcell packet distribution is invented
merely to guarantee same totals. Source-compatible local acceleration may be
required but is not introduced as a free rescue parameter.

**Pros:** changes the control objective/actuator least; addresses a physical
question distinct from A; reuses lane-conservation, finite-receiving and
observation lessons. Offers an early negative conclusion if spatial aggregate
resolution/history already captures the relevant effect.

**Cons:** current source packet does not establish the required hidden-history
pair or rate-action distinction. Binding geometry, sensing, initialization and
distributed merging could still be substantial. More cells may resolve the
effect, making it a resolution finding rather than a retained-metadata finding.

**Dependencies/scientific consequence:** preserve G1. Select G2=C and C0 as G3;
if a viable task survives, discuss G4 before adopting its law. Finding adequate
aggregate spatial closure is a legitimate negative outcome, not a prompt to
remove observations. This recommendation is about scope continuity and a bounded
test, not a claim that C is likely positive.

### T — gap-aware ramp release timing

Review whether choosing the timing of individual releases relative to approaching
mainline gaps creates a genuine need for local traffic information. The source
task responds to gap detections and vehicle-dependent acceleration; it is not
just optimization of a common coarse open-loop rate schedule. Establish the
source's sensing, lane restrictions, release/safety constraints and complete
objective first. Compare information retention, actuator timing and physical
model changes separately; do not attribute a combined change to hidden state.

**Task/model-chain result sought:** a task where release timing affects which
merging opportunity is usable, with explicitly justified additional information
and a fair timing-capable aggregate/reference comparison. Source performance
is a planning lead, not an established gradient result.

**Pros:** existing ramp-control literature directly links local gap information
to actual release decisions; clearer action connection in the inspected packet
than adding geometry alone. Reuses A's acceleration/travel-time and C's finite
opportunity concepts in a genuinely different control problem.

**Cons:** changes actuator parameterization and usually feedback/sensing; discrete
safe releases and event timing make gradients harder. Existing gains also depend
on source geometry/lane restrictions and driver models. A source comparison with
more detectors or a different actuator is not our matched-history certificate.

**Dependencies/scientific consequence:** explicit G2=T and scope amendment for
timing/sensing; retain complete waiting accounting and common feasible safety
rules. One-vehicle releases are the source behavior, not approval to integerize
the project simulator. Known complete-state sufficiency still applies; T is no
escape from it. Requires its own plan before detailed review.

### R — representation and gradient fidelity with known fine initialization

Keep a source-grounded freeway/rate-control task, but ask what happens when a
reduced model projects away physical state that a richer reference retains.
Compare physically justified closures and retained representations using common
underlying scenarios, parameters, controls and objective. The discarded state
may be known in the reference initialization or reconstructible in principle.
The scientific claim becomes the accuracy and control usefulness of a chosen
reduction, not impossibility of reconstruction by an ideal controller with full
history and exact dynamics.

**Task/model-chain result sought:** a minimum justified representation whose
forward/control sensitivities are closer to the richer reference than competing
reductions, with declared projection and ablations. Recovery studies are reusable;
RM10 is not reopened as if its negative information result had been overturned.

**Pros:** directly fits a study in which detailed initial traffic is known;
removes the logical conflict of trying to make that complete state become newly
unknown. Keeps rate control/TST and uses existing physical model families.

**Cons:** explicitly changes the current strong-history necessity claim. A
successful study would demonstrate the value of the selected representation
relative to tested reductions, not that aggregate information can never recover
it. Independent gradient/control validation would remain future experimental
work; arbitrary weak baselines or loss terms remain unacceptable.

**Dependencies/scientific consequence:** G2=R explicitly reopens G1 with user
approval. Keep numerical correctness and independent usefulness distinct.
This is a potentially productive reformulation, not an unchanged continuation
whose easier acceptance criterion is silently substituted for RM10's.

## Proposed C0 sequence and outcome boundary

The user now selects C-revised and approves this sequence. C0 is a new admission
work step, not the old RM9 R1 or a full model-design commitment.

1. **Find the genuine task.** From primary sources, bind finite-lane geometry,
   actual rate-control setting, queues/receiving, speed observations and initial
   knowledge. A hypothetical lane illustration alone is not enough. Retain all
   available history; a real aggregate-only start must be evidenced.
2. **Check the strong spatial rival.** Determine what adequate aggregate spatial
   resolution and public geometry already capture under the same raw information.
   A lane-resolved macroscopic model retaining lane information is a relevant
   intermediate rival, not evidence that that information is unnecessary.
   Refinement cannot quietly supply unobserved fine initial coordinates.
3. **Check residual information and rate relevance.** Establish a supported reason
   for unresolved state after history and how common feasible metering-rate
   changes can affect complete TST. Different whole-lane totals or different
   per-cell measurements are not hidden-history witnesses. A plausible spatial
   mechanism alone can be recorded but cannot pass as a full positive result.
4. **Report the admission result before deep formulation.** If the admitted
   history reconstructs relevant state, or no genuine task/history/action
   connection is supported in the bounded primary frontier, conclude scoped
   negative. If a defensible task survives, present the smallest G4 law/info
   decisions needed for detailed C. Do not automatically enter T, R or deep C.

This is literature/static analysis only. No cell count, merge penalty, detector
removal, stochastic realization or microscopic lane law is fixed in advance.
Methodological soundness and feasibility govern ordering; no numerical cost or
claimed positivity probability is used to rank choices.
