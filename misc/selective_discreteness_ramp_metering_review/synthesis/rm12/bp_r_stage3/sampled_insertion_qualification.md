## Static deductions

of mass; floor differences count descriptors only. Reset leaves population
unchanged. Identical own inputs and completed transfer histories through an
update imply identical newborn records through that update. No future reference
trajectory enters. Conditional causality does not prove the preceding traffic

Artificially attaching distinct threshold ranks as different count values at
the same point would be inconsistent. For distinct neighboring positions, count
differences must satisfy the road's density/storage bound. This is a consistency
check, not a fabricated within-cell queue or an excuse to merge distinct records.
Existing labels retain the preceding exact source correction; a source located
on an existing path still needs the selected field/transfer transcription's
proper attachment. No global constant-label assumption is restored.

**Local effect after insertion.** For a source-free segment, triangular FD and
one active zero-passing restriction at fixed speed below free speed, conservation
determines the saturated following trace and void ahead. The derived following
flow is positive when that speed is positive. This explains how the motion
condition creates traffic service without adding a scalar capacity penalty.
It is a moving trace, not a universal cap at every fixed section or a new node
allocation formula. Future node receiving must come from the same wave solution.

## What is still required to call the forward chain closed

Prescribing path segments removes a feedback dependency that the full task has:
CM needs own downstream traffic, which is affected by the same paths; node flows
and accepted lateral sources depend on that field. A source-free single-road
theorem cannot simply be applied as a theorem for the whole endogenous multilane
metered problem. V03 expressly distinguishes this general endogenous case.

Qualification must therefore provide a determinate own-speed estimation/update
and a compatible joined solution for the approved node and accepted sources,
including simultaneous encounters. Retaining the interfaces is necessary;
naming an implicit wave operator is not sufficient. This remains reviewer-owned
work under the approved contracts. If it requires a changed physical law or
reference update, return to the smallest global decision before adoption.

Clearance also needs proof or a qualified integrable tail. A local restriction's
free acceleration does not prove that interacting traffic clears. A closed forward
map is distinct from nontrivial all-stream TST rate leverage and useful gradients.
Source threshold boundaries may change the descriptor set; no derivative claim
is made here.
