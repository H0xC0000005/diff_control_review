# Synthesis directory guide

Synthesis artifacts are grouped by the sprint that first owns the contract,
matrix, analysis or decision inventory. Empty sprint directories are omitted.

| Directory | Contents |
|---|---|
| [`s01/`](s01) | Candidate-task matrix, minimum source map and explicit exclusions. |
| [`s02/`](s02) | Admissibility, evaluator, gap, adoption and predecessor-overlap registers. |
| [`s03/`](s03) | Route B common contract and contrast/information audit. |
| [`s04/`](s04) | Diagnostic technical contract and living decision inventory. |
| [`s05/`](s05) | Analytical certificate source and rendered PDF. |
| [`s07/`](s07) | Reachable-preparation analysis source and rendered PDF. |
| [`s08/`](s08) | Approved exact-prefix feasibility contract. |
| [`s10/`](s10) | Claim–evidence matrix, successor options and approved next-step ordering. |
| [`s11/`](s11) | Temporary-closure recovery admission and metric matrix. |
| [`s12/`](s12) | Advice–merge–service mechanism-admission matrix. |
| [`s13/`](s13) | M2 analytical contract/certificate and deferred research-readiness roadmap. |

Keep a LaTeX source beside its rendered PDF. Place a new artifact in the sprint
that owns its first scientific decision; cross-link it from later sprints rather
than copying it. Do not place new artifacts directly in this directory root.

The targeted M2 review is defined by the root-level
[`s13_00_...` plan](../s13_00_m2_analytical_contract_certificate_review.md).
Its formula-bearing contract and certificate are retained together in `s13/`.
The accepted later-stage roadmap is also retained there and is explicitly
deferred pending colleague discussion.
