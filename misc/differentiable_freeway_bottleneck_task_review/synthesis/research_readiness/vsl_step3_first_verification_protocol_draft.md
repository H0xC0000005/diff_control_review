## The question the verification answers

Under one common speed advice, can an initially omitted ending-lane statistic
change the correct complete-time prediction and speed decision? If so, does
one scalar repair the omission, and does the complete-objective gradient
correctly guide useful feasible changes within the defined task?

These remain separate claims: information sufficiency, decision relevance,
derivative correctness and within-task action quality. A compact peer
reproducing the lane model is a minimum-information result, not a failed
comparison. Useful perturbations in another traffic model are an optional
later transfer question, not a current Step 3 closure requirement. Later
native-reference sections below retain their historical extension scope;
the selected coupled law still needs its dependent Q1–Q3 protocol update.

The analytical observer certificate uses an envelope stronger than a finite

## Future forward and derivative checks

Forward correctness precedes derivative interpretation. A later approved
execution must verify paired conservation, input/output constraints, physical
terminal vacancy, complete cohort clearance and objective accounting. It must
also verify A+E/G prediction equality with equal inputs and inspect the declared
limits. A match to a shared-equation implementation is internal correctness.

Trace advice through normalized early receiving, completed preparation,
physical handoff and eligibility times, competing continuing arrivals,
residual forced service and complete TST. Use both stable smooth references
and the full valid forward domain.

Record preparation-branch changes, eligibility endpoints, queue onset/emptying
and pulse-end service changes. The nominal closed domain has slack upstream
terminal receiving and nonbinding forced-source sending; a failed domain
condition is an admission failure, not a clipping branch.

Inside stable event regimes, compare three objects separately: the continuous
analytical derivative, the implemented numerical forward model's directional
differences, and its AD derivative. Require the implemented forward value and
sensitivity to converge toward the continuous reference as numerical error
is reduced. AD agreeing with differences of an inaccurate discretization
does not satisfy that requirement.

Use double precision and a recorded feasible perturbation-step ladder.
At advice bounds use feasible one-sided perturbations. Event cases remain
in forward reporting; derivative comparisons there use an explicitly stated
one-sided/event contract. Freezing arrival/event times, adding smoothing or
dropping difficult forward cases would reopen G3/G4.

The later execution proposal must fix solver resolution, perturbation sizes,
absolute/relative error budgets and clearance residual tolerances before
held-out outcomes. Derive them from the reference's conditioning and declared
numerical errors. This methodology review does not invent numbers without
an implementation error model or reuse unrelated urban defaults.
