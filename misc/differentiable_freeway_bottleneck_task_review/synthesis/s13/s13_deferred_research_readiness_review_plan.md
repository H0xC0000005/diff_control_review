# Deferred VSL research-readiness review plan

Date: 2026-10-01. Status: **Accepted roadmap; deferred pending colleague discussion.**
Parent: [S13 M2C-A closure](../../reporting/s13/s13_99_m2_certificate_sprint_closure.md).

## Purpose

Preserve the accepted route from the S13 conditional certificate to a
research-ready VSL lane-drop study without opening further work now. This plan
is a continuation option, not an active sprint or implementation authority.

## Stage 1 — model-family robustness and minimum information

Review a small preregistered transfer/service family, causal deletion ablations
and the nested representation ladder from strong aggregate history, through an
aggregate-plus-merge-pressure scalar and grouped lane state, to fuller per-lane
state only where compression fails.

Deliver a bounded theoretical claim, candidate minimum state, ablation matrix,
model-form failure regions and stop conditions. Scalar sufficiency is an
admissible result.

## Stage 2 — traffic domain and reference-evaluator admission

Review source-supported geometry, demand, response and receiving ranges;
separate calibration from held-out evidence; and select a richer evaluator that
can represent the admitted mechanism. Tool availability does not substitute for
traffic-validity evidence.

Deliver an admitted domain/evaluator pair or close the applied branch as
theory-only.

## Stage 3 — matched gradient-usefulness protocol

Freeze matched preparations, common actions, complete all-stream accounting,
the aggregate/scalar/lane model ladder, derivative checks, active-set handling,
independent perturbation evaluation, held-out regimes, metrics, tolerances,
seeds and negative-result interpretation.

Deliver an outcome-blind protocol separating forward fidelity, derivative
correctness and downstream gradient usefulness.

## Stage 4 — integrated research-ready plan freeze

Consolidate hypotheses, equations, components, interfaces, data/configuration,
implementation and validation order, computational resources, reproducibility,
user checkpoints, stop rules and report products into an approved execution
plan under the repository Phase A–C workflow.

## Prospective research task

> Determine whether augmenting a strong aggregate lane-drop VSL model with the
> minimum merge-preparation state improves prediction of useful common-VSL
> perturbations in a richer reference model, and whether fuller lane resolution
> adds value beyond that compressed state.

## Opening boundary

The VSL continuation is intentionally set aside before colleague discussion.
Opening Stage 1 requires a new explicit user instruction and a bounded review
proposal. No stage, simulator work or experiment is active.
