# FB0026 — stronger aggregate response baseline

Frejo/Papamichail/Papageorgiou/De Schutter (2019), TRC 100, 15–33,
[DOI](https://doi.org/10.1016/j.trc.2019.01.001).
[Archived author report 19-022](../../archive/full_text/FB0026.pdf), 23 PDF pages;
cover reconciles journal identity. Methods and calibration/validation/conclusions
inspected, E3 at those locations; author-report page numbers below.

Sections II–III, pages 3–8, equations 1–6 and 13–14: segment density
(veh/km/lane), dynamic mean speed (km/h), lane-weighted total flow (veh/h),
origin queue and external boundary data. Continuous speed relaxation and
advice-dependent FD parameters with a scalar noncompliance parameter;
that parameter is not a fraction of discrete driver classes. Minimum/maximum
operators and exponential FD; inherited speed floor is an explicit model
assumption, not permission to add clipping to our project.

Sections VII–IX, pages 14–20: calibrate one morning, validate other days and
short uncongested VSL periods using Dutch A12 field data. Table VI reports mean
relative speed errors 12.84%/30.08%/9.29% for Hegyi/Carlson/Frejo formulations.
Same homogeneous state resolution; response-law/calibration differences matter.
Long-horizon comparisons are partly informed by congestion-triggered signs;
they are not fully open-loop action tests. Table V versus following prose also
differs in Carlson's mean (10.03% versus 10.3%); do not silently resolve it.

Adoption: strong B0 response family, not chosen implementation. Recalibrate for
voluntary advice and common bottleneck, audit storage/positivity/bounds before
use. No matched information-resolution ranking or external gradient check.
More calibration flexibility is a cost and confound to control, not novel
cohort evidence. Extends FB0003 (2018), not an independent confirmation.
