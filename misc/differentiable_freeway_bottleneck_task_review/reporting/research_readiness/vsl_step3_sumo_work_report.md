## Assumptions and limits

One ordinary reference vehicle represents one vehicle equivalent for the
population bridge. Native positions are projected to the predictor's stated
uniform mean profile, not declared identical to a continuum field. Compatible
integer counts in the analytical proportions demonstrate only mass arithmetic;
no native initialisation or physical parameter size was admitted.

SUMO is benchmark reference truth, not automatic empirical truth for this
road. Default source descriptions of same-edge merge priority conflict; a
later build must use explicit priority and inspect generated logic. Native
connection geometry and internal-link behavior can change travel/service.
Normal terminal lane changes can weaken the forced-work mechanism. These
are why the terminal interpretation is a scientific gate.

No work factor or numerical fit was selected. Positive large-work and common-
fastest small-work results remain conditional. Effective parameters cannot
be chosen using held-out optima, and a saved state is not assumed causally
equivalent to a replay.
